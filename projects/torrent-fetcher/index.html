$Torrent Fetcher

NodeExpressReactViteMongoDBDockerStripeCheerio

Criei o Torrent Fetcher para resolver um problema bem prático: encontrar magnet links sem precisar abrir uma dezena de abas em trackers diferentes. A API em Node/Express varre mais de 15 provedores nacionais e internacionais em paralelo (com Cheerio para scraping e Undici para as requisições), normaliza e ordena os resultados por seeds ou data de adição, e usa o MongoDB Atlas como camada de cache: buscas repetidas num intervalo de 10 dias são respondidas direto do banco, e a atualização do cache compara e injeta apenas os itens novos. O frontend em React + Vite consome essa API com uma experiência leve e responsiva, com checkout via Stripe. Todo o sistema é containerizado com Docker e também roda como funções serverless na Vercel, com atenção a detalhes de produção como a separação entre variáveis de build e de runtime e o contorno de bloqueios de IP de alguns provedores.
