$Exato Imóveis/Real State

NodePlaywrightVanilla JSBulmaIAMongoDB

Exato Imóveis was a personal project that came from the difficulty I had when searching for foreclosure properties on the Caixa website. Since the website provides a daily updated spreadsheet containing all properties and their main details, I decided to create my own filtering system. I processed and standardized the data so it could be imported into MongoDB Atlas. Before that, however, I enriched the dataset by running automated lookups to save photo URLs and gather information that was not included in the spreadsheet. During the data processing stage I realized that, by using the address string, I could call the Google Maps API to convert it into latitude and longitude, allowing geolocation search, which is now almost essential for any real estate website. However, I never implemented this feature because it would have introduced costs, and until that point the entire project had not cost a single Brazilian real (free non-relational database and a free Node server). Within a week I developed the entire interface in pure JavaScript, without frameworks, fully responsive and fast. I also implemented filters for amenities such as pools and barbecue areas, which are not available in the Caixa website search. The filter I built allows searches across multiple regions simultaneously with much more granular criteria, including number of rooms, land size, building size, number of bedrooms, discount percentage, number of parking spaces, presence of a balcony, and more.
