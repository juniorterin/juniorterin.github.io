$Chepita

NodeExpressOauthAzure

Chepita was born out of my reluctance to learn .NET just to build simple hotsites. Hosting costs for that kind of platform were not cheap, which bothered me since it felt like a massive solution for a relatively small problem. I decided to build a Node middleware (to consume a very old and problematic legacy backend) so I could create HTML pages that consumed a REST API. This way I only needed to pay for a machine running Node, while hosting the HTML for free on GitHub Pages. The pages were fed through a pipeline I built on Bitbucket, a service that I also introduced at the company, which at the time used a different versioning system instead of Git.
