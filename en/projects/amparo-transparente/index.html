$Amparo Transparente

Next.jsReactTypeScriptMongoDBTailwindRechartsThree.jsGSAP

Amparo Transparente is a public transparency portal I built for my hometown, translating spending, revenue, procurement, contracts, and legislative activity into language any citizen can actually understand, without having to navigate the notoriously clunky official government portals. The site is built with Next.js (App Router) and Tailwind, with Recharts handling the data visualizations and MongoDB Atlas (via Mongoose) as the data layer. The part I'm most proud of is the ingestion pipeline: TypeScript scripts that pull data daily from the São Paulo State Court of Auditors (TCE-SP), the national procurement platform (PNCP), the City Council, and the city hall's GRP portal, handling inconsistent formats, encoding issues, and pagination quirks unique to each source, then populating the database incrementally through a scheduled GitHub Actions workflow. I also used Three.js and GSAP to add a more dynamic visual layer without getting in the way of the data itself. It's the kind of project that blends data engineering, automation, and real social impact.
